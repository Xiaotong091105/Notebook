Keyword Search Demo

An ids-only inverted index (term → set of patient ids) with plain keyword querying: term, AND, OR. Results are an unranked set of patients. Everything runs in your browser; uploaded files never leave this page.

1 · Data

Rows sharing an id are pooled into one patient.

2 · Search

Type OR (capitals) between groups: hypertension OR htn. Terms are lowercased and stopwords dropped, as in the index; no / not / without / denies are kept as ordinary terms. Quotes do not make a phrase (an ids-only index has no positions).

3 · Score against known answers synthetic data only

The generator records which patients truly have each condition or symptom (affirmed, not negated). Gold = those patients. Score is set-based per patient.
