# Notebook

## Working conventions

- Before discussing anything in this project, read `_index.md` first for background — it indexes the concept/learning-map docs in this project
- Update the _index.md file by giving one brief sentence when a new document is created in Concepts, Action, Memo, Ideas, Learning-maps folders
- When pushing changes to GitHub, name the branch/PR after the folder the changes belong to, suffixed with "Log": Action folder → "Action Log", Concepts folder → "Concept Log", Learning-maps folder → "Learning Map Log", Memo folder → "Memo Log", Ideas folder → "Idea Log". If a change spans multiple folders, split it into separate branches/PRs per folder where practical.
